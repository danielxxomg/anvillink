# Exploration: test-harness-hardening

## Intent

Prevent recurrence of gens v0.3.0 Paper 1.21.5-114 / Java 25 regressions with a hardened harness that **fails in CI before it fails on a gens host**. The three production regressions shared one root pattern: tests exercised contracts on a different classpath, with different I/O, and with different TileState lifecycle than the Paper 1.21.5 host.

This change does NOT add user-visible features. It tightens the test harness so the existing specs (`platform-compatibility`, `repair-economy`, `repair-signs`) are trustworthy across Paper 1.18.2 → 1.21.11 → 1.21.5-114 without shipping host-coupled bytecode or Adventure.

## Gaps (Shadow/Adventure + Config/File I/O + Sign Lifecycle)

**Shadow / Adventure / Paper remapper gap:**
- `shadowJar minimize()` without keep rules removes `adventure-text-serializer-legacy` and `gson` serializer classes not statically referenced. `relocate("net.kyori:adventure-text-minimessage", ...)` alone leaves `adventure-api` / `adventure-serializer-legacy` on host `net.kyori` — linkage splits `Component` identity across classloaders (`net.kyori` host vs `anvillink.libs.kyori` shaded). Paper's legacy remapper thread (`io.papermc.paper:paper-api` remapped jar) remaps NMS/Bukkit but does not remap relocated Adventure. A build that compiles fine on Paper 1.18.2 with relocated Adventure can still `NoSuchMethodError` on Paper 1.21.5 where host Adventure 4.17+ changed `LegacyComponentSerializer` signatures. CI `build.yml Verify JAR` only grepped `paper|vault`; it never asserted legacy presence nor relocation completeness.

**Config vs File I/O gap:**
- `FileConfigurationPort` is hand-rolled line-scan (avoids SnakeYAML 1.30 vs 2.2 skew). The shipped `config.yml` is the operator's source of truth, yet no test loaded it from `src/main/resources/config.yml` as a **file** through `Files.readString + AtomicReference<ConfigSnapshot>` path. Synthetic strings missed inline comments, quote-vs-comment disambiguation (`"a # b"` must not strip), `worlds:` two-level indent, and `admin.target-distance` scalar. No round-trip assertion that the **expanded `${version}` resource** and the **shipped default** parse validly on every `processResources` change.

**Sign lifecycle gap:**
- Paper 1.21+ `SignChangeEvent` lifecycle: event holds mutable `String[4] lines`; after `setLine` the server coalesces lines into a fresh `TileState` snapshot post-event. Writing PDC/color to a snapshot taken **before** `setLine` silently orphans identity. `DyeColor.BLUE` via `Sign.setColor` is legacy `org.bukkit.DyeColor` vs modern `net.kyori.adventure.text.format.NamedTextColor` backing — not covered by `FakeSign` or `WorldMock`. `MockBukkit.mock()` without `MockBukkit.load(AnvilLink)` bypasses `JavaPlugin.onEnable` wiring (`getDataFolder()`, `saveDefaultConfig`, `FileConfigurationPort(File)`, `PdcSignIdentity` PDC namespace, `SignLifecycleListener` registration, `VaultEconomyGateway` service lookup), so lifecycle tests call listener methods directly rather than firing `pluginManager.callEvent`.

**Context7 notes consulted:**
- `Paper` (`/websites/jd_papermc_io_paper_1_21_11`) — `PluginBootstrap.bootstrap(BootstrapContext)` / `createPlugin(PluginProviderContext)` lifecycle, `LifecycleEventOwner` / `BootstrapContext` hierarchy; paper-test bootstrap is the blessed host-classpath test surface for Paper 1.21+, but requires remapped runtime.
- `MockBukkit` (`/mockbukkit/mockbukkit`, `/websites/mockbukkit_en`) — `MockBukkit.mock()`/`unmock()` global state, `MockBukkit.createMockPlugin()` vs `MockBukkit.load(plugin)` plugin-load semantics, `ServerMock.addSimpleWorld`/`addPlayer`/`ServicesManager.register(Economy)` driver API. Limitation explicitly noted: `BlockState`/`TileState` snapshot divergence, `Sign.setColor(DyeColor)` legacy path, scheduler synchronous — real Paper TileState copy-on-write and post-event line coalescing are not fully modeled.
- `Adventure` (`/kyoripowered/adventure-docs`, `/websites/papermc_io_adventure`) — `MiniMessage.deserialize` + `LegacyComponentSerializer.legacySection().serialize(Component)` relocation pitfall: all `net.kyori` must relocate together, legacy/gson serializers must be kept from `minimize()`, host Adventure 4.17+ signature changes surface only on host classpath.

**ShadowJar / minimize gotchas (Paper remapper thread):**
- `minimize()` keeps only classes statically reachable from the plugin's `main` + `plugin.yml`-declared entry points. `LegacyComponentSerializer` referenced only via `MessagePort.render`'s `try { serialize } catch (Throwable)` is kept, but `adventure-serializer-gson` / `adventure-serializer-legacy` transitive deps may be dropped if not `implementation`-declared — hence `adventure-legacy` must be an explicit `implementation`, not transitive. `relocate("net.kyori","...libs.kyori")` must apply to **all** Adventure modules, not just `minimessage`; selective relocation splits `Component` identity. Paper's remapper thread already remaps Bukkit NMS; doubling `paper-api` into the jar would defeat the remapper — exclusions must stay.

## Recommendation (2-Slice Shape)

Adopt **Approach A as the baseline** (MockBukkit-only hardening + artifact-contract tests) for `test-harness-hardening`; treat **Paper Test Framework as a follow-up proposal** if Slice 1+2 still leave a host-classpath blind spot after measurement, and **retain Docker smoke as a non-optional evidence gate** (not a TDD tier) by promoting Paper 1.21.5-114 to a mandatory `smoke.yml` row in Slice 1.

### Slice 1 — Artifact Contract (no host Paper needed, catches bugs #1 + #2, blocks `minimize()`/relocate regressions)

Goal: make `clean build` fail on the bugs that hit gens before any server runs.

- **Shadow/relocation contract test** (extends `BytecodeFloorTest` pattern, runs after `shadowJar`):
  - Assert release JAR: contains `io/github/danielxxomg/anvillink/libs/kyori/text/serializer/legacy/LegacyComponentSerializer.class` + `adventure-api` classes under `.../libs/kyori/` (9-class smoke from fix 9f190b6), contains no `org/bukkit`/`org/bukkit/craftbukkit`/`net/minecraft/server`, bytecode for `io/.../anvillink/**` (excluding `/libs/`) is major 61, `plugin.yml` has expanded `${version}` and `api-version 1.13`.
  - Extend `build.yml Verify JAR` to `jar tf | grep -q libs/kyori/legacy || exit 1` (now present) and fail if any relocated `net/kyori` remains unrelocated (`jar tf | grep '^net/kyori' && exit 1`).
  - Harden `shadowJar { minimize { exclude(...) } }` or keep explicit `implementation(libs.adventure.legacy)` so future `minimize()` cannot strip legacy.

- **Shipped-config round-trip** (file I/O, not synthetic strings):
  - `ShippedConfigRoundTripTest` + `FileConfigurationPortTest.defaultConfigInlineComments_accepted` pattern generalized: `Files.readString(Path.of("src/main/resources/config.yml")) → Files.writeString(temp/config.yml) → new FileConfigurationPort(file)` asserts `activationEnabled==true`, `priceHand==12000.00`, `priceAll==25000.00`, `targetDistance==8`, message keys like `repair-success` present, `feedback.enabled/sound/particles` defaults, commented `worlds:` example not parsed. Also assert `quote # not stripped` (`messages.g: "a # b"` → `"a # b"`), `worlds.world.hand` with inline comment, and that bare `price: 25.00` scalar fails closed with `missing price.hand` retained prior. This is the regression that gates bug #1.

- **Legacy smoke without host Paper:**
  - `MiniMessagePortTest` extension: render a tagged message containing MiniMessage tags, then force `LegacyComponentSerializer` absence to assert `catch (Throwable)` fallback still returns raw `withPlaceholders` (covers Paper 1.21.5 host mismatch without needing 1.21.5 runtime). Add a compile-time assertion that `MiniMessageMessagePort` imports `net.kyori...Component` which actually resolves to `...libs.kyori...Component` after relocation (artifact contract implies it).

- **Smoke promotion:** make `Paper 1.21.5-114 / JDK 21` a **mandatory** `smoke.yml` row (`continue-on-error:false`) with SHA256-gated `compatibility/evidence.json` entry. Keep probe `Paper 26.2/J25` as `continue-on-error:true`. `smoke.yml` should continue to gate `allMandatoryPass(...) && paperCertified(...)` before `paper26Certified`.

Slice 1 is independently shippable and retroactively covers both v0.3.0 packaging/config regressions with zero Docker and zero Paper Test Framework.

### Slice 2 — Bootstrap / Sign Lifecycle End-to-End (catches bug #3, proves PDC+BLUE survives event coalescing)

Goal: replace direct `listener.onSignChange(event)` calls with `MockBukkit.load(AnvilLink)` plugin-bootstrap fidelity so tests run through the same `JavaPlugin` classloader and `TileState.update` path the server does.

- **MockBukkit plugin-bootstrap harness:**
  - Add `AnvilLinkPluginLoadTest` / `SignBootstrapE2ETest` that does `ServerMock server = MockBukkit.mock(); var plugin = MockBukkit.load(AnvilLinkPlugin.class)` (or `MockBukkit.createMockPlugin` → `load` as per MockBukkit 4.110 API), asserts `getDataFolder().exists()`, `saveDefaultConfig` writes `config.yml` with inline comments, `FileConfigurationPort` loads via `new File(getDataFolder(),"config.yml")`, PDC namespace `danielxxomg:anvillink_repair_sign` is permanent, and `SignLifecycleListener`/`RepairActivation` wiring from `onEnable` matches direct-instantiation wiring.

- **SignChange → PlayerInteract end-to-end:**
  - Fire `SignChangeEvent` via `server.getPluginManager().callEvent(create)` (not `listener.onSignChange` directly), then assert `block.getState() instanceof Sign` has `getLine(0)=="[repair]"`, `getLine(1) in {"HAND","ALL"}`, `getColor()==BLUE`, `PdcSignIdentity.has(state)==true`, and that `ts.update(true,false)` was called (observable via `FakeSign.updated` or MockBukkit `SignMock`). Cover both the fresh-`TileState` path and the fallback where `fresh !instanceof TileState` but original `state instanceof TileState` (test double).
  - Drive `PlayerInteractEvent` through `InteractionFilter.shouldProceed` → `RepairActivation.activate(SignId, UUID)` → `VaultEconomyGateway.withdraw` → `BukkitEquipmentPort.applyRepair` → feedback `play` on `Success(non-zero)` swallowed, mirroring `SignIntegrationTest` 7.1/7.4/7.5/7.6/7.7 but now through the loaded plugin's adapters rather than ad-hoc `Proxy Economy`. Keep `OffHand` single-charge, `InsufficientFunds` no-repair, `NoProvider` fail-closed, `NoEligibleItems` no Vault call.
  - Cover edit/break without `manage` (cancelled, PDC unchanged) and tampered-text fail-closed (`InvalidResponse` tampered, no charge) through the event bus, not direct listener.

Slice 2 depends on Slice 1's artifact/config contracts for setup but reuses the same `paper-api-test 1.21.11` + MockBukkit 4.110 substrate — no new host runtime. If MockBukkit 4.110's `SignMock` still hides the stale-`TileState` divergence (residual risk), Slice 2 at least proves the **fallback + fresh-state pattern** persists under the plugin-bootstrap lifecycle; the remaining delta is exactly what Paper Test Framework would add and can be measured after Slice 2 ships.

## Risks

- **MockBukkit fidelity ceiling:** MockBukkit 4.110 `WorldMock`/`SignMock`/`TileState` is not Paper 1.21.5 TileState copy-on-write. Slice 2 narrows gap by loading the real plugin and firing events through `callEvent`, but if MockBukkit still returns the same instance from `getState()` the stale-vs-fresh mutation remains unobservable. Risk mitigated by keeping both paths (fresh + fallback) and by Slice 1 artifact assertions; if evidence still shows drift after Slice 2, promote Paper Test Framework as a follow-up.
- **`minimize()` re-strips legacy:** future `implementation` changes or `shadowJar { minimize { } }` tuning can re-drop `adventure-legacy` classes. Risk mitigated by Slice 1 `jar tf | grep libs/kyori/legacy` mandatory Check and by pinning `adventure-legacy` as `implementation` (not transitive).
- **Dual Paper API classpath:** adding `paper-api-test 1.21.11` alongside `paper-api 1.18.2 compileOnly` via `testImplementation` must not duplicate `org.bukkit` capability or leak into `shadowJar`. Current exclusions (`exclude dependency("io.papermc.paper:paper-api")`) are compile-only; test classpath uses `paper-api-test` for Folia types — must assert `GRADLE_USER_HOME="$PWD/.gradle" ./gradlew dependencies --configuration testRuntimeClasspath` has no split `paper-api` duplicates.
- **Toolchain/JDK skew:** `toolchain 21` + `--release 17` prod vs `--release 21` test is correct but fragile if contributors run with `JAVA_HOME=25` without `mise`. `smoke.yml` must gate `Paper 1.18.2` on `JDK 17` and `1.21.5-114` on `JDK 21`; `BytecodeFloorTest` already proves major 61 regardless of runner JDK.
- **Shipped resource drift:** `src/main/resources/config.yml` is the regression seam — any edit that adds `worlds:` entries or changes inline comments can re-break parsing if `stripInlineComment` regresses. Slice 1 round-trip must run on `processResources`-expanded output, not just source, to catch token expansion drift.
- **Tag vs suite confusion:** `smoke.yml` filters by `--tests "*integration*" "*platform*"`; there is no `@Tag` smoke/agnostic split. Introducing `@Tag("smoke")` now would orphan existing tests. Keep suite-filtering; add tags only if a real Paper-host tier appears (Paper Test or Docker) that warrants isolation from fast unit runs.
- **Evidence SHA256 staleness:** `compatibility/evidence.json` SHA256 values are `0*`-`5*` placeholders today; `CompatibilityEvidenceSchemaTest` / `EvidenceGatedSupportTest` / `SemVerSeparationTest` already gate `allMandatoryPass` + `paperCertified` vs `paper26Certified`. Adding `Paper 1.21.5-114` row requires bumping evidence SHA256 and build numbers truthfully — blocked on a real smoke execution that populates SHA256.
- **Vault provider variance:** `VaultEconomyGateway` `fractionalDigits()` is used by `ValidatedPrice` representability at activation; MockBukkit `Proxy Economy` with `fractionalDigits=2` does not prove a provider with `fractionalDigits=-1` or `0`. Slice 2 economy tests must keep the proxy matrix but smoke's real economy provider is the final proof.
- **Scope creep into SDD spec:** this change is harness-only — no `repair-economy` / `repair-signs` requirement delta. Must not invent new domain behavior or `SignRecord` fields to "test for" — only harden how existing behavior is exercised.
